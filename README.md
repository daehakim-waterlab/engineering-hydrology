# Engineering Hydrology

An online textbook for the undergraduate Engineering Hydrology course, Department of Civil Engineering, Jeonbuk National University.

**Read it at <https://daehakim-waterlab.github.io/engineering-hydrology/>** · [PDF](https://daehakim-waterlab.github.io/engineering-hydrology/engineering-hydrology.pdf)

Built with [Jupyter Book](https://jupyterbook.org/) 1.x, with the same setup as the [Hydraulics](https://github.com/daehakim-waterlab/hydraulics) book.

## Layout

- `_config.yml`: book settings (MathJax, code execution, PDF, footer "© Daeha Kim" and license).
- `_toc.yml`: four parts and thirteen chapters. Chapter, section, figure and table numbers are written by hand in the chapter files.
- `intro.md`: the front page, with the notation table.
- `chapters/chNN_*.md`: one MyST Markdown notebook per chapter. Python code goes in `{code-cell} python` blocks and runs on every build, so figures, tables and numbers always come from the code. Tag a cell `hide-input` to fold its code under the figure, `remove-input` to show only its output (e.g. a table), or `remove-cell` to run it without showing it (plot style; exercise answers glued into the text with `{glue:text}`).
- `_static/custom.css`: table styling for phones and dark mode.

## Writing rules

- American English spelling (vapor, meter, modeling). SI units only. Formulas first published in US customary units are given in SI form, and each converted form is checked against the original in code.
- Examples use invented numbers or synthetic data generated by the code. No case-study catchment.
- All text, figures, examples and exercises are original. Reference books appear only under "Further reading".
- Figure palette: series `#2a78d6`, `#eb6834`, `#1baf7a`; text `#0b0b0b`, secondary `#52514e`; background `#fcfcfb`.

## Build locally

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter-book build .
open _build/html/index.html
```

The PDF needs XeLaTeX (TeX Live); `jupyter-book build . --builder pdflatex` writes `_build/latex/engineering-hydrology.pdf`. CI builds it for you.

## Publishing

`.github/workflows/deploy.yml` builds the HTML and the PDF on every push to `main` and deploys them to GitHub Pages (Settings → Pages → Source: "GitHub Actions"). A code cell that raises an error, or any build warning, stops the deployment, and the previous version stays online. A failed PDF build does not stop it.
